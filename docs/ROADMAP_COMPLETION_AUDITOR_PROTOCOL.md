# Engineering roadmap audit — ownership

The autonomous roadmap-completion auditor is owned by [Motocicl](https://github.com/concreteballs/Motocicl/blob/main/docs/ROADMAP_COMPLETION_AUDITOR_PROTOCOL.md).

Engineering Core remains the source of truth for its engineering roadmap and [implementation status](IMPLEMENTATION_STATUS.md). Motocicl may audit those documents against repository evidence and report stale or incomplete statuses, but it must not rewrite engineering requirements or mark a discipline's domain acceptance complete without the evidence required by Engineering Core.

This file is retained as a navigation pointer. The complete operating protocol and cycle-side acceptance tests live in Motocicl.
